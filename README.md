# ノート（iPad mini 用 手書きノート）

HTML / CSS / JavaScript だけで動く手書きノートのWebアプリです。外部ライブラリやサーバー側の処理は使っていません。

## 機能
- **本棚**：ノートを本棚に並べて表示します。右上の「＋」でノートを追加。ノートを長押しすると、名前・表紙の編集／1冊まるごとPDF書き出し／削除ができます。
- **ノート**：元に戻す・やり直す、ペン1・ペン2、消しゴム、設定（▽）
  - 上部に2本のペン（初期設定：黒ペン・赤ペン）。選択中のペンをもう一度タップすると、そのペンの設定が開きます
  - ペンの種類：ボールペン（筆圧対応）／マジックペン／マーカー
  - 太さはスライダーで調整、色は8色
  - 消しゴムは触れた部分だけを消します（本物の消しゴムと同じ）。太さはスライダーで調整でき、「このページを全消し」もできます（元に戻すで戻せます）
- **ページ**：用紙は白紙・罫線・方眼からページごとに選べます。指で左右にスワイプするとページをめくれます（最後のページで次へめくると、新しいページが追加されます）。左上のボタンでページ一覧を開き、並べ替え・削除・用紙の変更ができます。
- **長押し（指）**：このページ／1冊まるごとをPDFに書き出し
- **パームリジェクション**：Apple Pencilだけで描き、指はスワイプ・ピンチでの拡大・長押しに使います（ペン設定の「指でも描く」で切り替えられます）。
- **自動保存**：線を描くたびに端末内（IndexedDB）へ保存します。
- **バックアップ**：本棚の「⋯」からJSONファイルに書き出し・復元ができます。

## iPadで使う手順
Service Worker（オフラインで使うための仕組み）は **HTTPS** でしか動かないため、このフォルダを無料の静的ホスティングに置いて使います。

1. このフォルダ（`index.html` があるフォルダ）を、次のどちらかにアップロードします。
   - **Netlify Drop**（https://app.netlify.com/drop）：フォルダをドラッグ＆ドロップするだけ
   - **GitHub Pages**：リポジトリにプッシュし、Pages を有効にする
2. iPadのSafariで公開されたURLを開きます。
3. 共有ボタンから **「ホーム画面に追加」** を選びます。
4. ホーム画面のアイコンから起動します（全画面で開き、オフラインでも使えます）。

> **データについて**：ノートはiPadの中にだけ保存されます。ホーム画面に追加して使うと、Safariが自動でデータを消すことはありません。それでも念のため、ときどき「⋯ → バックアップを書き出す」で「ファイル」アプリに保存しておくと安心です。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` / `css/style.css` | 画面の構造と見た目 |
| `js/app.js` | 本棚・画面の切り替え・バックアップ |
| `js/editor.js` | 描画・ジェスチャー・ページ操作・ペンの設定 |
| `js/render.js` | 線と用紙の描画（画面・サムネイル・PDFで共通） |
| `js/pdf.js` | PDFの生成（ライブラリを使わない自前実装） |
| `js/db.js` / `js/settings.js` | 保存（IndexedDB）とペンの設定 |
| `sw.js` / `manifest.json` / `icons/` | PWA（オフライン対応・ホーム画面のアイコン） |

アプリ本体を更新したときは、`sw.js` の `CACHE` の名前（例：`ipad-note-v2` → `ipad-note-v3`）を変えると、iPadで次に起動したときに更新が反映されます。
