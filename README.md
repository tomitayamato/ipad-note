# ノート（iPad mini 用 手書きノート）

HTML / CSS / JavaScript だけで動く手書きノートのWebアプリです。外部ライブラリやサーバー側の処理は使っていません。

## 機能
- **本棚**：ノートを本棚に並べて表示します。右上の「＋」でノートを追加。
  - 段分け：「⋯ → 段を追加」で段（例：仕事・趣味）を増やせます。段の名札の「⋯」から名前の変更・並べ替え・削除
  - 並べ替え：ノートを長押しすると持ち上がるので、そのままドラッグして別の位置・別の段へ
  - 長押しして動かさずに離すと、名前・表紙の編集／別の段へ移動／PDF書き出し／削除のメニュー
- **ノート**：元に戻す・やり直す、ペン1・ペン2、消しゴム、設定（▽）、写真
  - 上部に2本のペン（初期設定：黒ペン・赤ペン）。選択中のペンをもう一度タップすると、そのペンの設定が開きます
  - ペンの種類：ボールペン（筆圧対応）／マジックペン／マーカー。太さはスライダー
  - 色：基本の8色（黒・赤・青・緑・黄・オレンジ・紫・白）。「色を編集」でパレットの色を自由に変更、虹色の丸でパレットにない色も選べます
  - 消しゴムは触れた部分だけを消します。太さはスライダーで調整でき、「このページを全消し」もできます
  - **2本指タップで元に戻す、3本指タップでやり直す**
  - **紙の向き**：2本指でつまんでひねると紙が回ります。上下左右（0°・90°・180°・270°）の近くでは吸い付きます。「⋯ → 紙の向きをまっすぐに戻す」で元に戻せます
  - **図形の自動補正**：線・円・楕円・四角・三角を書いて、最後にペンを少し止めるときれいな形に（ペンの設定でオン／オフ）
- **写真・スクショ**：ツールバーの写真ボタン（または長押しメニュー）から貼り付け。画像の上からペンで書き込めます。画像を指で長押しすると移動・拡大縮小・削除
- **ページ**：指で左右にスワイプすると、紙のようにめくれます（最後のページで次へめくると新しいページを追加）。用紙は白紙・罫線・方眼からページごとに選べ、ページ一覧で並べ替え・削除ができます
- **長押し（指）**：写真の貼り付け、このページ／1冊まるごとのPDF書き出し、ページ追加、全消し
- **パームリジェクション**：Apple Pencilだけで描き、指はスワイプ・ピンチでの拡大・長押しに使います（ペン設定の「指でも描く」で切り替えられます）。
- **自動保存**：線を描くたびに端末内（IndexedDB）へ保存します。
- **バックアップ**：本棚の「⋯」からJSONファイルに書き出し・復元ができます。

## iPadで使う手順
Service Worker（オフラインで使うための仕組み）は **HTTPS** でしか動かないため、このフォルダを無料の静的ホスティングに置いて使います。

1. このフォルダ（`index.html` があるフォルダ）を、次のどちらかにアップロードします。
   - **Netlify Drop**（https://app.netlify.com/drop）：フォルダをドラッグ＆ドロップするだけ
   - **GitHub Pages**：リポジトリにプッシュし、Pages を有効にする
2. iPadのSafariで公開されたURLを開きます。
3. 共有ボタンから **「ホーム画面に追加」** を選びます。
4. ホーム画面のアイコンから起動します（全画面で開き、オフラインでも使えます）。

> **データについて**：ノートはiPadの中にだけ保存されます。ホーム画面に追加して使うと、Safariが自動でデータを消すことはありません。それでも念のため、ときどき「⋯ → バックアップを書き出す」で「ファイル」アプリに保存しておくと安心です。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` / `css/style.css` | 画面の構造と見た目 |
| `js/app.js` | 本棚（段分け・並べ替え）・画面の切り替え・バックアップ |
| `js/editor.js` | 描画・ジェスチャー・画像・ページめくり・ペンの設定 |
| `js/render.js` | 線・画像・用紙の描画（画面・サムネイル・PDFで共通） |
| `js/shapes.js` | 図形の自動補正 |
| `js/pdf.js` | PDFの生成（ライブラリを使わない自前実装） |
| `js/db.js` / `js/settings.js` | 保存（IndexedDB）とペンの設定 |
| `sw.js` / `manifest.json` / `icons/` | PWA（オフライン対応・ホーム画面のアイコン） |

アプリ本体を更新したときは、`sw.js` の `CACHE` の名前（例：`ipad-note-v5` → `ipad-note-v6`）を変えると、iPadで次に起動したときに更新が反映されます。
